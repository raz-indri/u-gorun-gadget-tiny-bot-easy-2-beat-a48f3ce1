Slow-Tide Dip Bot: a tiny deterministic paper-trading bot for make.fun's "Tiny Bot, Easy $2: Beat Buy-and-Hold on Solana" bounty. It starts invested like buy-and-hold, holds only symbols whose 18-bar EMA sits above their 44-bar EMA, and buys dips 2% below the 12-bar average once they bounce off the 6-bar low. No clock, no network, no randomness — the same bars always give the same orders.

## Run it

```sh
node main.ts
```
